# Introduction

!!! note
	This workshop gives you hands-on experience with the Foundry Toolkit in Visual Studio Code to build, test, and evaluate an AI agent for a business scenario.

## Learning Objectives

By the end of this workshop, you should be able to:

- Configure an Azure AI Proxy-hosted model in the Foundry Toolkit.

- Build an agent by combining a model and instructions with Microsoft Learn tools through Model Context Protocol (MCP).

- Create evaluation datasets and manually assess agent responses.

- Compare agent versions and use AI-assisted metrics to evaluate response quality at scale.

## Lab Outline

The lab is organized into five chapters that take you from environment setup through agent building and evaluation with the Foundry Toolkit for VS Code.

1. **Part 1 - Get Started:** Launch the workshop in GitHub Codespaces, retrieve your Azure AI Proxy credentials, and verify that the Foundry Toolkit is installed.
2. **Part 2 - Agent Building:** Configure the workshop model, create a social media manager agent in Agent Builder, add Microsoft Learn MCP tools, test the integration, and save the agent locally.
3. **Part 3 - Human Evaluations:** Generate an evaluation dataset, review and rate agent responses, enhance the agent instructions, and compare two agent versions.
4. **Part 4 - AI-Assisted Evaluations:** Add quality metrics, use a model as a judge, and compare automated scores with your manual assessments.
5. **Part 5 - Summary:** Review what you learned and explore considerations for production deployment, monitoring, and continuous improvement.
